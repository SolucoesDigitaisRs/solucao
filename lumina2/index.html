SOBRE A Lúmina

Personalização com significado.

A LÚMINA nasceu para transformar ideias simples em peças especiais. Trabalhamos com gravação e corte a laser para criar produtos personalizados para pessoas, famílias, empresas e eventos.

Cada projeto é pensado para ter identidade própria — porque uma peça personalizada deve ser diferente de qualquer outra.

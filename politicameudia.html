🔒 Política de Privacidade

Aplicativo Meu Dia

LGPD • Lei nº 13.709/2018

Última atualização: Janeiro de 2025

1. Compromisso com sua Privacidade

🔒 Zero coleta de dados

O MeuDia foi desenvolvido com privacidade por padrão (privacy by design). Não coletamos, não armazenamos em servidores, não vendemos e não compartilhamos nenhum dado pessoal dos usuários.

2. Quais dados o app utiliza?

O aplicativo utiliza exclusivamente os dados que você mesmo inserir:

  • Informações financeiras (contas, valores, datas)
  • Tarefas e compromissos pessoais
  • Eventos da agenda
  • Anotações de texto livre

Esses dados são processados e armazenados somente no seu dispositivo, através do IndexedDB do navegador. O desenvolvedor não tem acesso a nenhum desses dados.

3. Armazenamento Local

Todos os dados ficam salvos no IndexedDB e localStorage do navegador que você utiliza.

Eles não saem do seu dispositivo — não há sincronização em nuvem, não há envio de dados para servidores externos.

Você pode apagar todos os dados a qualquer momento pela seção Backup → Zona de Perigo, ou limpando os dados do navegador nas configurações do sistema.

4. Cookies e Rastreamento

O MeuDia não utiliza cookies de rastreamento, pixels de marketing, ferramentas de analytics, SDKs de redes sociais ou qualquer tecnologia de monitoramento de comportamento do usuário.

O único dado salvo fora do IndexedDB é a data dos últimos backup/restauração, gravado no localStorage apenas para exibição informativa na interface.

5. Fontes externas (Google Fonts)

O aplicativo carrega fontes do Google Fonts via CDN ao ser aberto online.

Essa requisição está sujeita à Política de Privacidade do Google:

https://policies.google.com/privacy

Para uso completamente offline, o arquivo HTML pode ser adaptado com fontes locais.

6. Seus Direitos (LGPD)

Como todos os dados estão exclusivamente no seu dispositivo, você já possui controle total sobre eles.

  • Acessar: todos os dados são visíveis dentro do próprio app.
  • Exportar: via Backup → Exportar Backup.
  • Corrigir: editando qualquer registro diretamente no app.
  • Apagar: via Backup → Zona de Perigo.
  • Portabilidade: o arquivo de backup JSON pode ser usado em qualquer sistema compatível.

7. Alterações nesta Política

Esta política pode ser atualizada. Quaisquer alterações serão refletidas nesta mesma seção do aplicativo. Recomendamos revisão periódica.
